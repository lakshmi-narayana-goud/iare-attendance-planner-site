INSTALLATION GUIDE

How to install the IARE Attendance Planner extension

Choose the browser you use for Samvidha and follow the matching steps. You never need to give your Samvidha password to this website.

Before you beginUse the official Samvidha portal for your login. The Attendance Planner is a browser companion, not a replacement for Samvidha.

Microsoft Edge on PC

  1. Open the IARE Attendance Planner Edge listing.
  2. Select Get and approve the browser prompt.
  3. Open Samvidha and sign in normally.
  4. Open the extension from the Edge extensions menu.

Firefox Desktop

  1. Open the Mozilla Add-ons search.
  2. Open the published IARE Attendance Planner listing.
  3. Select Add to Firefox.
  4. Open Samvidha and launch the planner from Firefox's add-on controls.

Firefox for Android

Install the current Firefox for Android and check the Mozilla listing for mobile compatibility. Firefox's supported extension set can change between releases, so use the current listing as the source of truth.

After installation

Refresh the Samvidha page after installing the extension. If the planner does not appear, confirm that you are logged in, the extension is enabled, and you are using a supported browser.
