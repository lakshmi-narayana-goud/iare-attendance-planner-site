# IARE Attendance Planner — SEO-ready static site

## What was added
This version is structured for legitimate, long-term search visibility rather than keyword stuffing.

### Pages
- `/` — main landing page
- `/install.html` — installation guide
- `/edge.html` — Microsoft Edge guide
- `/android.html` — Android/Firefox guide
- `/attendance.html` — attendance and target explanation
- `/privacy.html` — privacy/security
- `/robots.txt`
- `/sitemap.xml`

### SEO work included
- Descriptive page titles
- Unique meta descriptions
- Canonical URLs
- Open Graph metadata
- `SoftwareApplication` JSON-LD
- `WebSite` JSON-LD
- Crawlable internal links
- XML sitemap
- robots.txt
- Mobile responsive design
- Useful, distinct pages for real student intents
- Clear disclosure that this is student-built, not official IARE software

## REQUIRED BEFORE DEPLOYMENT

Replace every occurrence of:

`https://YOUR-DOMAIN.example/`

with your real public website URL.

This appears in:
- `index.html`
- `install.html`
- `edge.html`
- `android.html`
- `attendance.html`
- `privacy.html`
- `robots.txt`
- `sitemap.xml`

Then:

1. Deploy the site on a real HTTPS domain.
2. Create/verify the property in Google Search Console.
3. Submit `/sitemap.xml`.
4. Use URL Inspection to request indexing for the homepage and important guide pages.
5. Keep the pages accessible without login and do not block Googlebot.
6. Add real screenshots of the extension and, if possible, short original usage documentation.
7. Share the site naturally with IARE students, college communities and relevant project pages.

## Ranking expectations

No legitimate technique can guarantee that Google will place this site first for broad searches such as `IARE` or `Samvidha`. Those searches may have strong official or established results.

The realistic strategy is to become highly relevant for searches such as:
- IARE attendance planner
- IARE attendance extension
- Samvidha attendance extension
- IARE Samvidha attendance
- IARE attendance calculator
- IARE attendance planner Edge
- IARE attendance extension Android
- Samvidha attendance planner
- how to check IARE attendance
- IARE attendance target 75 80 85

The site intentionally avoids hidden keywords, doorway pages, fake reviews, cloaking, automated spam, or other manipulative tactics. Google explicitly recommends people-first content and warns against search-engine-first content and keyword stuffing.
