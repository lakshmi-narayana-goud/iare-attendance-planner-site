# IARE Attendance Planner — Static Website

A zero-backend, responsive static landing/documentation site for the IARE Attendance Planner browser extension.

## Files
- `index.html` — complete site
- `styles.css` — responsive styling
- `script.js` — small smooth-scroll enhancement
- `assets/favicon.svg` — site icon

## Deploy for free

### GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root` (or `/`).
6. Save. GitHub will provide the public URL.

### Cloudflare Pages / Vercel
Upload/connect the repository and use the project root as the static site. No build command is required.
