FAQ

Common questions.

Is IARE Attendance Planner free?

Yes. The planner and this documentation site are intended to be free for students.

What is IARE Attendance Planner?

IARE Attendance Planner is a student-built browser extension designed to help IARE students understand attendance information, attendance targets, subject-wise attendance and timetable status available through their Samvidha session.

Is this an official IARE Student App?

No. It is a student-built browser extension and is not presented as the official IARE Student App, MyIARE application, or official Samvidha service. The planner is intended as a companion for students.

Is this an official IARE application?

No. It is a student-built browser extension and is not presented as an official IARE product. Samvidha itself is the IARE campus management portal.

Can I calculate my IARE attendance percentage?

The planner helps students understand attendance percentage and target levels such as 75%, 80% and 85% using the attendance information available through their Samvidha session.

Can I see how many classes I can miss?

Yes. The planner provides a can-bunk calculation that estimates how many upcoming valid classes can be missed while remaining above your selected attendance target.

Does it change my attendance?

No. The planner is for viewing and calculating attendance-related information. It does not provide a mechanism to edit or fabricate official attendance.

Do I need a new account?

No separate Attendance Planner account is intended. Use your normal Samvidha session.

Why is my data not appearing?

First confirm that you are logged into Samvidha, that you are using a supported browser, and that the extension is enabled. Refresh the Samvidha page after installation.

Is Chrome support available?

Chrome support is currently being updated. The updated Chrome version will be announced on this website when it is ready. Until then, use one of the currently supported browser paths listed above.

Does the phone version work exactly like desktop?

The mobile experience depends on Firefox for Android's current extension support and the extension's mobile UI. Keep Firefox updated and use the mobile-specific instructions above.
