CHOOSE YOUR DEVICE

Install in a few steps.

Pick the path that matches your device. The extension is free.

🖥️ COMPUTER

Microsoft Edge

Recommended for Windows PC and laptop users.

Open Edge Add-ons →
  1. Open the listing above.
  2. Select Get / Get extension.
  3. Confirm the browser permission prompt.
  4. Open samvidha.iare.ac.in and log in normally.
  5. Open the IARE Attendance Planner from the browser extension menu.
🦊 COMPUTER

Firefox Desktop

Use the official Mozilla Add-ons listing when the published listing is available.

Find on Mozilla Add-ons →
  1. Open the Mozilla Add-ons page.
  2. Search for IARE Attendance Planner.
  3. Open the verified listing published for this project.
  4. Select Add to Firefox.
  5. Open Samvidha and use the extension.
📱 ANDROID

Firefox for Android

Firefox for Android supports compatible Firefox extensions. Install Firefox first, then use the Mozilla listing.

Open Mozilla Add-ons →
  1. Install/update Firefox for Android.
  2. Open the Mozilla listing above.
  3. Add the extension if Firefox offers it as compatible.
  4. Open Samvidha in Firefox.
  5. Use the browser's extension/add-ons controls to open the planner.
Mobile extension support can change with Firefox releases. If the add-on does not appear, use the latest Firefox for Android and check the listing again.
Important: Never give your Samvidha password to the Attendance Planner website or to another person. Log in directly on the official Samvidha portal.

FAQ

Common questions.

Is IARE Attendance Planner free?

Yes. The planner and this documentation site are intended to be free for students.

Is this an official IARE application?

No. It is a student-built browser extension and is not presented as an official IARE product. Samvidha itself is the IARE campus management portal.

Does it change my attendance?

No. The planner is for viewing and calculating attendance-related information. It does not provide a mechanism to edit or fabricate official attendance.

Do I need a new account?

No separate Attendance Planner account is intended. Use your normal Samvidha session.

Why is my data not appearing?

First confirm that you are logged into Samvidha, that you are using a supported browser, and that the extension is enabled. Refresh the Samvidha page after installation.

Does the phone version work exactly like desktop?

The mobile experience depends on Firefox for Android's current extension support and the extension's mobile UI. Keep Firefox updated and use the mobile-specific instructions above.
