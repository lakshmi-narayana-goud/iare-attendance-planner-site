MICROSOFT EDGE

IARE Attendance Planner for Microsoft Edge

Windows and laptop users can install the published Edge extension and use the planner while working with their normal Samvidha session.

Direct installationOpen IARE Attendance Planner in Microsoft Edge Add-ons →

What Edge users can see

  • Overall attendance and subject-wise attendance.
  • 75%, 80% and 85% target calculations.
  • Classes you can potentially miss while staying above a target.
  • Current/NOW class and remaining timetable periods.
  • Next timetable day information.

Using the extension

Log into Samvidha directly, then open the Attendance Planner from the browser extension menu. If the panel is not visible, refresh the Samvidha page and verify the extension is enabled.

Security reminder

Never send your Samvidha username or password to a person claiming to install the extension for you. Install it from the browser store and authenticate directly on Samvidha.
