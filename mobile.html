IARE Attendance Planner on Android

The mobile path uses Firefox for Android because browser extension support on Android is browser-dependent. This page explains the safest installation path and what to check when the planner is not visible.

Start hereInstall or update Firefox for Android, then check the current Mozilla Add-ons listing for IARE Attendance Planner compatibility.

Installation

  1. Install the latest Firefox for Android.
  2. Open the Mozilla Add-ons search.
  3. Open the IARE Attendance Planner listing if it is offered as compatible.
  4. Add the extension.
  5. Open Samvidha in Firefox and use the browser's add-on controls.

If the extension does not appear

  • Update Firefox for Android.
  • Check whether the add-on is currently marked compatible for your Firefox release.
  • Refresh the Samvidha page after installation.
  • Make sure you are using the official Samvidha portal and are logged in.

Mobile experience

The mobile interface is designed to be easier to use on a phone, but browser-level extension capabilities can differ from desktop. The current Firefox and Mozilla listing determine compatibility.
